# モデル対応

2026-10-20、初期実装の検証状況。

| 構造 | Residual | Attention/MLP | 備考 |
|---|---|---|---|
| 数値検証用極小Transformer | 独立NumPy参照と全観測点一致 | QKV/Softmax/Head寄与/SwiGLUを再構成 | 固定ランダム重み。事前学習済みではない |
| Qwen3 | 小型ランダム構成で検証 | QK Norm/RoPE/GQA/SwiGLUを再構成 | Qwen3-0.6B実重みの両OS GPU検証を継続 |
| GPT-2 | 小型ランダム構成で検証 | QKV/GELU/出力射影を再構成 | 実重みの正式対応は今後の実測による |
| その他の構造・量子化 | 非対応 | 非対応 | 未検証の取得能力を表示しない |

実モデル登録時は「取得可能・未検証」。実行時の再構成チェックに合格した範囲と実行条件を記録する。
生成はKV Cacheで新しい位置の値のみ保存する。極小モデルは全コンテキストを再計算するが、保存は追加位置のみ。
生成された最終トークンにも実際のforwardを行ってから軌跡を付ける。

観察から因果性を断定しない。Logit Lensは最終Norm/LM Headを用いた途中表現の読み出しであり、
途中層が実際に出した確率とは表記しない。Tuned Lens・Activation Patching・Ablationは拡張機能として非対応表示。
