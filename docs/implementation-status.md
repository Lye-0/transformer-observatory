## 今回の対象外と現在の制約

- 大規模モデルの実験は、ユーザーの「今は行わない」という指示に従い対象外。環境不足による停止とは区別する。
- 任意のモデルサイズ・全Transformer構造・全量子化方式への対応や、Flash Attention内部の直接取得は保証しない。
- 介入先・出力読出しは元入力のPrefillに限定する。Residual PatchはEmbedding・Block出力に対応し、Attention後のResidual Patch・生成中の介入は非対応。
- 追加射影はt-SNEを提供し、UMAPは提供しない。t-SNEは全4,096観測点と設定RAM予算を上限とし、上限超過時は一部抽出せず拒否する。
- 観察・投影・介入を区別する。取得できない値や未学習のLensを生成して対応済みと表示しない。

## 2026-10-21のモデル管理更新

- 解析画面の「モデルを追加」から、入力中のプロンプト・条件を維持してModel Managerへ移動。登録後は追加したモデルを選択する。
- 標準のモデル置き場・Hugging Faceキャッシュ・追加した探索先を上限付きで検出。途中候補、中止、上限到達、読み取り失敗を表示する。
- 絶対パス入力・バックエンドOS上のフォルダー選択、構成の確認、登録時のTokenizer／safetensors／fingerprint照合を提供する。
- 登録と探索先を永続保存。ファイル消失時は利用不可を示し、移動後は同一fingerprintを条件に保存場所を更新する。
- Windowsの自動テストとChromeで登録から実解析まで確認。今回の実解析はランダム重みの小型GPT-2構成を使い、事前学習済みモデルの品質検証とは区別する。WSLの今回変更の再実測は未実施。

具体的な操作・API・探索上限は[ローカルモデルの検出と登録](model-registration.md)を参照。この更新で量子化・長文性能などの残作業を完了扱いにしない。
