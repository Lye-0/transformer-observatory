## 今回の対象外と現在の制約

- 大規模モデルの実験は、ユーザーの「今は行わない」という指示に従い対象外。環境不足による停止とは区別する。
- 任意のモデルサイズ・全Transformer構造・全量子化方式への対応や、Flash Attention内部の直接取得は保証しない。
- 介入先・出力読出しは元入力のPrefillに限定する。Residual PatchはEmbedding・Block出力に対応し、Attention後のResidual Patch・生成中の介入は非対応。
- 追加射影はt-SNEを提供し、UMAPは提供しない。t-SNEは全4,096観測点と設定RAM予算を上限とし、上限超過時は一部抽出せず拒否する。
- 観察・投影・介入を区別する。取得できない値や未学習のLensを生成して対応済みと表示しない。

## 2026-10-21の3D表示・操作更新

- 主軌跡の全観測点に小さな円を表示し、現在の段階を大点、選択中のトークンの現在点を白い輪で区別する。凡例とホバー時のトークン・観測点番号を表示する。
- マーカーの描画サイズは画面上の5／8／16 CSS px。モデルの座標尺度やカメラ距離で巨大化しない。全軌跡・全観測点をバッチ描画し、座標値の変更や間引きは行わない。
- クリック判定も画面上の点の近傍に限定する。空白・線の途中・成長表示の未表示段階・右クリック・ドラッグで選択を変えない。Ctrl／Commandによる複数選択を維持する。
- カーソル位置へズームする。回転・平行移動・ズームの開始時に、ポインター付近の可視データの奥行きへ回転中心を合わせる。中心は視線上で動かし、現在の画面を飛ばさない。ドラッグ中は中心を固定し、全体の座標範囲や過去の中心までの距離で回転感度を下げない。減衰による操作後の余分な回転もなくす。
- 奥行きは近くのマーカー、可視線分、周辺点の中央値から求める。線だけが見える場合は視野で線分をクリップし、透視投影に合う補間を用いる。この補間はカメラ操作用で、観測点・実測値を追加しない。画面外・背後の点や、成長表示の未表示段階は基準にしない。表示データがない場合は既存の中心を維持する。
- ダブルクリックの注視変更は視線方向と対象の見かけの縮尺を保つ。初期の全体中心が遠くても、注視により不意にズームが変わらない。「全体を表示」でカメラを戻せる。
- `pnpm --dir frontend test` はクリック位置・拡大率・成長表示・重なり・可視奥行き・線分のクリップ・注視・操作経路と更新頻度を検証する14件。実際のOrbitControlsに同じ入力を与え、以前の中心までの距離と更新回数を変えても操作結果が揃い、解放後に動かないことを含めてCIで確認する。Windowsでテスト・本番ビルド・整形検査に合格。
- Windows Chromeで既存のQwen3-0.6Bの7トークン・57観測段階を使用し、Scientific／Displacement、点からInspector／タイムラインへの連動、約55倍の拡大でも点が小さいままの表示、空白クリック・ドラッグ・右移動・全体復帰・軽量表示・1280／1920px幅を確認。
- 回転中心を補正する更新では同じ実データを1920px幅・710pxのCanvas高で検証。「直接ズーム」「注視してからズーム」「平行移動してからズーム」「両端の点が画面外となる線の中央へズーム」の4経路で、60pxのドラッグの回転角はいずれも約16.7°。対象までの奥行きは約98〜138座標単位。操作開始時の画面の飛びと解放後の回転がないことを確認した。異なる経路の透視図で、すべての点の画面移動量まで同一になるという保証ではない。
- 共通3D部品の固定座標による2画面テストで、両方向のカメラ同期、成長表示の未表示点の除外、Ctrl複数選択と軽量表示切替を確認した。回転中心の更新後にも双方向の同期・段階選択・未表示点除外・軽量表示切替を再確認。実モデル2実験の比較解析やWSL・タッチ操作の再実測は今回実施していない。
