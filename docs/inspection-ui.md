# ピン比較と成分ヒートマップ

## ピンの表示と保持範囲

- Explorer上部の件数付き「ピン」ボタンで、移動・サイズ変更できる非モーダルパネルを開く。Inspectorとタイムラインは操作でき、レイアウトの表示領域を縮めない。
- 同じボタン、閉じるボタン、Escで閉じる。複数パネルがある場合、Escは最後に操作したパネルだけを閉じる。閉じる際にパネル内へフォーカスがあれば、開いた操作部品へ戻す。その部品が観測点切替で消えていれば、上部のピンボタンへ戻す。
- 見出しをドラッグして移動、右下をドラッグしてサイズ変更できる。各ハンドルは矢印キーでも操作できる。「位置とサイズを戻す」を提供し、画面サイズが変わっても閉じる操作へ到達できる範囲に収める。
- ピンは取得時のトークン位置・段階・Decodeステップ・値を保持する。タブ、トークン、段階の変更やパネルを閉じる操作では消えない。各ピンを個別に解除できる。
- 同じ対象の重複追加を防ぎ、3件目以降も先のピンを自動削除しない。指標は値ごとに指標名を表示する。
- 保持は当該Explorerの閲覧中のメモリー内。再読み込み、別ページへの移動、別トレースを開く操作では解除され、保存トレースへの永続書き込みは行わない。

## ヒートマップの意味と操作

- Inspectorとピンには全体のプレビューを表示し、「拡大して見る」で独立した成分パネルを開く。
- 1セルは受信したテンソルを行優先で平坦化した1成分。描画の折り返し位置は意味的な近さを表さない。成分番号は0始まりで、元の形状から多次元の添字を計算する。
- `attention_weights`では取得済みのHead対応表を使い、HeadとKey位置も表示する。その他のテンソルにHeadや意味的なラベルを推測して割り当てない。
- ホバーで文脈・成分番号・数値を表示し、クリックで成分と値を保持する。数値は表示用に3桁へ丸めず、受信した数値の文字列表現を用いる。矢印キー、Home／End、拡大ビューの成分番号入力でも選択できる。
- 拡大ビューにはセルの拡大・縮小、スクロール、移動モードのドラッグを提供する。ズーム後や同じ成分への再移動でも番号と値の対応を保つ。セル間の隙間・余白・ドラッグは新しい成分を選択しない。
- 拡大ビューは開いた時点の値を保持する。現在のInspectorが別の観測値に変わっても、パネルの文脈と数値を変更しない。

## 色範囲と取得上限

- 青を負、赤を正、0を中立色とし、数値範囲を凡例で表示する。
- 単独の表示は表示値の絶対値の最大、複数のテンソルのピンは全ピンの表示値から求めた共通の対称範囲を使う。ピンから開いた拡大ビューも、そのピンが残っている間は同じ共通範囲に従う。
- 色範囲の計算で取得値を書き換えない。空間・形状が異なる場合、同じ色や空間名だけで意味的な対応が保証されないことを表示する。
- 既存APIの先頭16,384成分の表示上限を維持する。元の全成分数と部分表示を区別し、番号入力は実際に受信した成分までに制限する。保存値や3D軌跡は削減しない。
- 描画用ビットマップの一辺は最大2,048pxとして拡大時のメモリー増大を抑える。選択は画面上のセル位置から元の成分番号へ対応させる。
- 読み込み中は前の対象のヒートマップを表示しない。リクエストの文脈を照合し、異なる対象の値を新しいトークン名でピンしない。

## 検証

2026-10-22、Windows Chromeで既存のQwen3-0.6Bトレースを使い、ピン表示前後のInspectorの寸法一致、段階・タブ・トークン切替、個別解除・再表示、共通色範囲、成分237／1023の実値、ズーム後のクリックと矢印キー、パネルのドラッグ・サイズ変更・Escとフォーカス復帰を確認した。APIの応答を遅らせ、古い図を表示せず読み込み中となることも確認した。

16,384成分の固定データ（元の形状は200×100の部分表示）で、成分16383の添字・実値、最大拡大、ドラッグ後の同じ番号への再移動、390px幅でのパネルの収まりと、キーボードによる位置・サイズ変更を確認した。これは実モデルの大規模推論や実機スマートフォンの検証ではない。

`pnpm --dir frontend test`は既存の3D操作14件と、共通色範囲・0と符号・セル判定・添字・パネル領域の5件、計19件。ビルドとソースの整形検査も確認する。
